# 生成图片保留与历史列表

## 规则

- 生成图片从**生成成功时间**开始完整保留 7×24 小时；另要求图片资产自身也创建满 7 天。
- 没有按用户或批次数量上限。单用户一天生成 100,000 张也不提前清理。
- 生图记录列表、批次发现、批次计数和待提交批次列表按**任务创建时间**滚动查询最近 7×24 小时，翻页仍受此条件限制。
- 保留数据库任务、提示词、状态、积分/消费记录。过期对象通过 `output_expired_at` 标识，不把成功任务改成失败，不退款或重跑生成。
- 第一版只清理配置中的本地 MinIO `generated/<user_id>/<uuid>.<ext>` 对象。上传原图、视频、外部 CDN/R2、无法确认来源的对象和无对应成功任务的孤立对象不动。
- 收藏、精选（含待审核）、素材库、有效画布、站点素材及后续任务输入引用均受保护。UUID 文件名匹配会保守保护域名别名下的同一对象，不跨用户合并资产。

## 删除与并发

迁移增加资产 `retention_pending_at`、`storage_deleted_at`、`retention_error` 和任务 `output_expired_at`。清理器先锁候选资产与关联任务，再检查完成时间和引用，在短数据库事务中标记过期；提交后才进行对象删除。对象删除没有持有数据库行锁。

引用表上的触发器对所引用的资产获取 KEY SHARE 锁，阻止在检查和标记之间插入引用；过期后的新引用返回错误。素材库通过资产 ID 保护，URL 引用通过 UUID 文件名保护。任务的收藏/精选变更同样受到保护。生产数据库中的所有这些引用表必须已存在后再执行本迁移；若以后新增引用表，应增加同样的保护和扫描。

存储删除失败保留 pending 状态与错误类型，下一轮重试。对象已删除但数据库写回失败时，同一个 S3 DELETE 可以安全重试。`storage_deleted_at` 只在删除请求成功后写入；报告中的 logical_bytes 是候选资产记录大小，不承诺实际释放同等磁盘块。

单实例 advisory lock 覆盖标记和删除阶段，避免多 worker 重复执行。游标扫描跳过受保护记录，扫描结束后回到开头，重新检查前轮失败项。单次最多 500 个候选，默认 500 个、每 60 秒一次；可调整批量与间隔。已启用或曾暂停版本控制的桶会被拒绝，避免只写删除标记却没有释放旧版本。

## 验证与启用

默认 `IMAGE_RETENTION_ENABLED=false`，代码部署本身不会启动自动删除。先在测试环境执行数据库迁移，再启动新版服务。前端/查询代码依赖新列，必须先迁移再更新应用。

```sh
# 在 user-server 目录，使用该项目的 uv 环境
uv run alembic upgrade head
# 默认只读预演，输出汇总与下一页游标
uv run python -m app.services.image_retention --limit 100 --max-batches 1
# 继续预演
uv run python -m app.services.image_retention --after-id <next_id> --limit 500 --max-batches 10
```

确认预演和备份策略后，才执行 `--apply` 或设置 `IMAGE_RETENTION_ENABLED=true`。通过 Compose 使用同名变量，调整配置后需要按正常发布流程更新服务。首次历史清理可用有界 `--apply --max-batches N`，不要并发启动额外脚本。生产变更遵守 Git 发布流程。

已过期的任务不再提供下载、导出图片或缩略图；仍可以查阅任务记录。生成图片链接和用户自行保存的 CDN 链接不能保证一同失效，第一版不负责远端副本清理。

删除不可逆，停止 worker 不会恢复文件。执行过清理后禁止降级删除 tombstone 列，以免已删除图片重新显示为可下载。回滚前先关闭清理，保留数据库标记，并使用理解这些标记的应用版本。

## 本地验证

在隔离 PostgreSQL 测试库导入生产**仅结构**快照（不含生产数据），从 `20261012_0100` 升级本迁移。设置 `TEST_DATABASE_URL` 为本机测试库，运行：

```sh
uv run pytest -q tests/test_image_retention.py tests/test_batch_progress.py tests/test_catalog.py tests/test_browser_exports.py tests/test_batch_uploads.py
```

测试覆盖 100,000 张近期图片不受数量影响、完成时间、7 天列表边界/翻页、引用保护、并发先后顺序、只读预演、版本桶拒绝、删除失败重试、保留成功任务状态以及过期输出隐藏。
