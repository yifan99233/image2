# 企业团队控制台权限边界

团队控制台是客户子站的独立管理域，不是 image2 平台后台，也不提供 Sub2API 管理入口。

| 角色 | 可见内容 | 可执行操作 | 明确不可见 / 不可执行 |
| --- | --- | --- | --- |
| 员工 | 团队控制台中的本人余额、Token 额度与用量、图片/视频额度与用量 | 使用 AI 工具、管理本人账号 | 成员名单、其他成员额度与用量、团队设置、平台配置 |
| 团队管理员 | 当前子站的团队成员、本人及全部成员额度与用量、协作设置只读 | 添加/移除普通成员，编辑每位成员的 Token 与图片/视频额度 | 修改团队名称、共享策略、任命管理员、平台后台、Sub2API 管理员 Key、其他客户数据 |
| 团队所有者 | 当前子站的团队设置、成员与管理员、本人及全部成员额度与用量 | 管理成员、任命或撤销团队管理员、修改协作设置、编辑每位成员额度 | image2 平台后台、模型渠道、Sub2API 管理员 Key、其他客户数据 |
| image2 平台管理员 | 所有子站的内部运维数据 | 开通子站、配置模型与网关、审计与支持 | 不通过客户团队控制台暴露权限 |

服务端权限由 `user-server/app/services/team_sharing.py` 的 `TEAM_CONSOLE_ROLE_PERMISSIONS` 集中定义，团队端所有接口位于 `/team-console/**`。普通员工仅能调用本人额度接口；成员列表、团队用量和额度修改接口均由服务端再次校验权限，不依赖前端隐藏按钮来实现隔离。

额度分为两项并由 Sub2API 原生执行：Token 额度绑定员工文本 Key，图片/视频额度绑定员工视觉 Key。`0` 表示不限额。管理员 Key 仅保存在服务端站点配置中，不会返回团队控制台。
