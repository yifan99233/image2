# admin-web 管理端 Web 需求与开发任务

## 项目定位

`admin-web` 是平台运营和管理员使用的后台。重点是可审计、可配置、可查询、可回滚，界面应采用标准后台信息架构：侧边栏 + 顶部用户区 + 表格列表 + 工具栏 + 抽屉/弹窗表单。

## 功能需求

### 管理员登录

- 独立登录页。
- JWT 会话保持。
- 401 统一退出。
- 基于权限控制菜单和按钮。

### 控制台

- 今日新增用户、今日充值金额、今日消耗积分、任务成功率、失败任务数。
- 最近充值订单。
- 最近失败模型调用。
- 积分异常提醒。

### 用户管理

- 用户列表：用户名、邮箱、手机号、状态、积分余额、注册时间、最后登录时间。
- 搜索：用户名、邮箱、用户 ID。
- 筛选：状态、注册时间、余额区间。
- 用户详情抽屉：
  - 基本资料。
  - 积分余额。
  - 充值订单。
  - 积分流水。
  - 创作任务。
- 操作：
  - 启用/禁用。
  - 重置密码。
  - 人工增加积分。
  - 人工扣减积分。
  - 添加备注。

### 积分管理

- 全平台积分流水列表。
- 支持按用户、业务类型、时间、任务 ID、订单号筛选。
- 人工调整必须填写原因。
- 支持异常流水标记和备注。

### 充值档位配置

- 档位列表：名称、金额、积分、赠送积分、总到账积分、推荐标签、排序、状态。
- 新增/编辑档位。
- 上架/下架。
- 排序调整。
- 删除只能软删除；已有订单引用过的档位不能物理删除。

### 模型管理

- 模型列表：
  - 模型名称、供应商、模型编码、能力类型、base URL、状态、是否推荐、是否稳定、排序。
  - API key 只展示脱敏值。
- 新增/编辑模型：
  - 基础信息：名称、描述、供应商、模型编码。
  - 连接信息：base URL、API key、请求路径、鉴权方式、超时、重试次数。
  - 能力配置：图片编辑、文生图、多图输入、最大上传数、支持分辨率、支持比例。
  - UI 标签：推荐、稳定、新模型、速度提示、风险提示。
  - 并发限制：每用户并发、全局并发、每日上限。
- 模型测试：
  - 输入测试提示词和测试图片。
  - 触发后台测试接口。
  - 展示成功/失败、耗时、响应摘要、错误原因。
  - 测试记录可查询。

### 模型消耗积分配置

- 按模型 + 能力 + 分辨率 + 尺寸比例 + 输出张数配置消耗积分。
- 支持生效状态、版本号、生效时间。
- 修改价格时要求填写变更原因。
- 历史价格不可覆盖，必须新版本生效。

### 创作任务管理

- 查看任务列表：用户、模型、状态、消耗积分、创建时间、完成时间、失败原因。
- 查看任务详情：输入图、提示词、结果图、模型请求摘要、积分流水。
- 支持手动补偿积分。
- 支持重试失败任务，重试前展示预计成本和风险。

### 管理员和权限

- 第一版至少支持超级管理员和运营管理员。
- 菜单和按钮按权限隐藏或禁用。
- 操作日志记录所有敏感动作。

## 非功能需求

- 所有列表必须服务端分页，不允许前端全量过滤。
- 所有危险操作必须二次确认。
- 所有配置表单必须有字段级校验。
- 密钥字段只能输入和覆盖，不能明文回显。
- 保存模型和价格配置后必须刷新用户端配置缓存。
- 后台操作必须显示操作者、操作时间和变更原因。

## API 依赖

管理端 Web 只调用 `admin-server`：

- `GET /admin/auth/public-key`
- `POST /admin/auth/login`
- `GET /admin/auth/me`
- `GET /admin/dashboard/metrics`
- `GET /admin/users`
- `GET /admin/users/{user_id}`
- `PATCH /admin/users/{user_id}/status`
- `PATCH /admin/users/{user_id}/password`
- `POST /admin/users/{user_id}/credit-adjustments`
- `GET /admin/credits/ledger`
- `GET /admin/recharge/plans`
- `POST /admin/recharge/plans`
- `PATCH /admin/recharge/plans/{plan_id}`
- `PATCH /admin/recharge/plans/{plan_id}/status`
- `GET /admin/models`
- `POST /admin/models`
- `PATCH /admin/models/{model_id}`
- `PATCH /admin/models/{model_id}/status`
- `POST /admin/models/{model_id}/test`
- `GET /admin/model-prices`
- `POST /admin/model-prices`
- `PATCH /admin/model-prices/{price_id}/status`
- `GET /admin/image-tasks`
- `GET /admin/image-tasks/{task_id}`
- `POST /admin/image-tasks/{task_id}/refund`
- `POST /admin/image-tasks/{task_id}/retry`
- `GET /admin/audit-logs`

## 开发任务

### T1 项目基础

- 初始化 React + TypeScript 项目。
- 配置路由、请求客户端、认证 store、权限 hook。
- 建立后台布局、菜单、面包屑、顶部用户区。

验收：

- 登录态、路由守卫、401 处理完整。
- 菜单可通过权限配置控制。

### T2 登录和控制台

- 实现管理员登录页。
- 实现控制台指标卡片和最近记录表。
- 接入 `/admin/dashboard/metrics`。

验收：

- 无权限不能进入后台。
- 指标 loading、empty、error 状态齐全。

### T3 用户管理

- 实现用户列表、搜索、筛选、分页。
- 实现用户详情抽屉。
- 实现启用/禁用、重置密码。
- 实现人工加减积分表单。

验收：

- 人工调整积分必须填写原因。
- 用户详情能看到余额、流水、订单、任务。

### T4 积分流水

- 实现积分流水列表和筛选。
- 实现异常标记和备注入口。

验收：

- 查询条件进入 URL query，刷新不丢失。
- 金额和积分展示格式统一。

### T5 充值档位配置

- 实现档位列表。
- 实现新增/编辑抽屉。
- 实现上下架、排序。

验收：

- 金额和积分必须为正数。
- 下架后用户端不再展示。

### T6 模型管理

- 实现模型列表和新增/编辑抽屉。
- 实现密钥脱敏展示。
- 实现模型启用/停用。
- 实现模型测试表单和测试结果展示。

验收：

- API key 不回显明文。
- 测试失败能展示错误摘要。

### T7 模型价格配置

- 实现价格配置列表。
- 实现新增价格版本表单。
- 支持按模型、能力、分辨率筛选。
- 支持停用价格版本。

验收：

- 修改价格不能覆盖历史记录。
- 新增价格必须填写变更原因。

### T8 任务管理和审计

- 实现创作任务列表和详情。
- 实现手动退款和失败任务重试入口。
- 实现审计日志列表。

验收：

- 敏感操作有确认和操作原因。
- 审计日志可按操作者和时间筛选。

### T9 质量收尾

- 补核心表单和服务层测试。
- 检查所有列表服务端分页。
- 补 README、环境变量、部署说明。
