# user-web 用户端 Web 需求与开发任务

## 项目定位

`user-web` 是普通用户使用的图片 AI 创作平台。首屏不是营销页，而是登录后的创作工作台：左侧功能导航、顶部账户/积分运营入口、中间创作表单、右侧实时作品流。

## 功能需求

### 账号与会话

- 注册：用户名/邮箱/密码注册，表单校验和弱密码提示。
- 登录：用户名密码登录，密码提交前获取后端 RSA 公钥并加密。
- 会话保持：JWT 持久化，刷新页面后恢复登录态。
- 退出登录：清理 token 和用户缓存。
- 401 处理：登录过期时统一提示并跳转登录页，带回跳地址。
- 账号菜单：个人资料、账号设置、积分记录、充值入口、退出。

### 创作工作台

- 左侧导航：
  - 首页。
  - 创作广场。
  - 图片 AI 编辑。
  - 图像 AI 生成。
  - 批量生图。
  - 批量改图。
  - 我的作品。
  - 商品主图工具分组：模特换装、多机位生成、多种人物姿势生成、OOTD 穿搭、商品抠图换背景、商品场景合成。
- 顶部栏：
  - 客服、签到、邀请、会员/授权入口。
  - 当前积分余额。
  - 账号头像和下拉菜单。
  - 明暗主题切换。
- 图片 AI 编辑页面：
  - 步骤 1：选择模型，模型卡片展示名称、描述、标签、能力、速度提示。
  - 步骤 2：上传图片，支持拖拽/点击，多图上传，数量上限从接口读取。
  - 步骤 3：文字描述，支持大文本输入、空值校验、历史提示词可后续扩展。
  - 步骤 4：选择分辨率，例如 1K/2K/4K，选项来自后端。
  - 步骤 5：选择生成尺寸比例，例如 1:1、4:3、3:4、16:9、9:16、3:2、2:3、21:9，选项来自后端。
  - 生成按钮展示本次预计消耗积分，余额不足时引导充值。
- 图像 AI 生成页面：
  - 无需上传原图，核心为模型、提示词、负面提示词、分辨率、比例、张数。
- 批量任务页面：
  - 支持批量上传和批量提示词。
  - 展示批次进度、成功数、失败数、总消耗积分。

### 作品与结果

- 右侧作品流：
  - 任务提交后出现处理中卡片。
  - 完成后展示原图/结果图。
  - 支持下载、预览、采集、推荐、删除、更多编辑。
  - 失败时展示失败原因和退积分状态。
- 继续编辑：
  - 基于某张结果图打开继续编辑输入区。
  - 展示继续编辑使用的模型、分辨率和预计消耗积分。
- 我的作品：
  - `我的作品` / `我的采集` tab。
  - 分类侧栏：全部、AI 创作、商品主图、营销素材、图片处理、创意玩法。
  - 状态筛选：全部、已采集、未采集、已推荐、未推荐。
  - 搜索提示词。
  - 卡片网格：缩略图、任务类型、提示词摘要、时间、预览、下载、推荐、采集、删除。
  - 批量选择、批量下载、批量采集。

### 积分与充值

- 顶部实时展示积分余额。
- 充值弹窗：
  - 展示当前积分。
  - 展示后端配置的充值档位：金额、获得积分、推荐标签、排序。
  - 选择档位后创建充值订单。
  - 展示支付二维码或支付跳转状态。
  - 轮询订单状态，支付成功后刷新积分。
- 积分记录：
  - 分页展示充值、消费、退款、后台调整、签到、邀请奖励。
  - 支持按类型和时间筛选。

## 非功能需求

- 全站请求封装统一处理 token、错误提示、401、请求取消。
- 表单提交期间禁用重复点击。
- 上传必须展示进度、格式错误、大小错误和数量上限。
- 列表页必须有 loading、empty、error、pagination。
- 大图预览使用懒加载，作品网格避免一次性加载全量图片。
- 积分价格、模型列表、尺寸选项不允许写死在组件里，必须来自接口或配置常量。
- 不直接调用模型供应商，不暴露模型 API key。

## API 依赖

用户端 Web 只调用 `user-server`：

- `POST /auth/register`
- `GET /auth/public-key`
- `POST /auth/login`
- `GET /auth/me`
- `GET /credits/balance`
- `GET /credits/ledger`
- `GET /recharge/plans`
- `POST /recharge/orders`
- `GET /recharge/orders/{order_id}`
- `GET /models`
- `GET /models/{model_id}/options`
- `POST /uploads/images`
- `POST /image-tasks`
- `GET /image-tasks`
- `GET /image-tasks/{task_id}`
- `POST /image-tasks/{task_id}/continue`
- `GET /works`
- `PATCH /works/{work_id}`
- `DELETE /works/{work_id}`
- `POST /works/batch-export`

## 开发任务

### T1 项目基础

- 初始化 React + TypeScript 项目。
- 配置 Vite、ESLint、Prettier、路径别名、环境变量。
- 建立目录：`services/`、`stores/`、`routes/`、`pages/`、`components/`、`features/`、`types/`、`theme/`。
- 实现统一请求客户端，参考 `testflow3.0/web/src/services/http.ts`。
- 实现 Zustand auth store，参考 `testflow3.0/web/src/store/authStore.ts`。

验收：

- 本地能启动。
- 未登录访问受保护页面跳转登录。
- 401 能清理登录态并跳转登录。

### T2 账号页面

- 实现登录页。
- 实现注册页。
- 实现 RSA 公钥获取和密码加密登录。
- 实现 `/me` 拉取当前用户信息。
- 实现登录后回跳。

验收：

- 登录成功后进入创作工作台。
- 注册成功后可登录。
- token 持久化和退出登录正常。

### T3 用户端布局和导航

- 实现左侧分组导航、折叠态、顶部栏、账号菜单、主题切换。
- 实现积分余额展示和刷新。
- 实现客服/签到/邀请/授权入口占位交互。

验收：

- 桌面端布局接近参考截图的信息结构。
- 窄屏时导航可折叠，不遮挡主操作区。

### T4 图片 AI 编辑工作台

- 实现模型列表和模型卡片选择。
- 实现上传组件，多图限制从模型配置读取。
- 实现提示词输入、分辨率选择、尺寸比例选择。
- 根据选择调用价格预估，展示预计消耗积分。
- 提交任务后创建处理中卡片并轮询结果。

验收：

- 模型/分辨率/尺寸都来自接口。
- 余额不足时不能提交，并弹出充值入口。
- 任务成功、失败、退款处理中都有明确 UI。

### T5 结果流和继续编辑

- 实现原图/结果图对比卡片。
- 实现预览、下载、采集、推荐、删除。
- 实现更多编辑菜单：压缩、水印、格式转换、尺寸调整、裁剪、旋转、翻转、边框、圆角、导出 PDF、合并。第一版可只做入口和状态提示，真正处理接口后续接入。
- 实现继续编辑区域。

验收：

- 操作有 loading 和成功/失败反馈。
- 删除有确认。
- 继续编辑会生成新任务并扣对应积分。

### T6 我的作品

- 实现 tab、分类、状态筛选、搜索、分页。
- 实现作品卡片网格和批量选择。
- 实现批量采集、批量下载导出。

验收：

- 作品数量多时仍分页加载。
- 空状态和搜索无结果状态可用。

### T7 充值和积分记录

- 实现充值弹窗、档位选择、创建订单、支付状态轮询。
- 实现积分流水页。
- 支付成功后刷新余额和流水。

验收：

- 档位来自接口。
- 重复点击不会创建多个订单。
- 订单超时/取消/支付成功状态清晰。

### T8 质量收尾

- 补充核心组件测试和服务层测试。
- 检查所有业务配置是否写死。
- 检查移动端/窄屏布局。
- 补 README 和环境变量说明。
